# PlantEd (In progress)
Smart Flora & Environment Analytics

## Summary

Browse through plants and see which ones are enthusiastic for sharing the same space with you.
Add plants to your household and generate (AI-powered) daily tasks that let you track your plants' needs.

## Features

* Displaying current weather details and air quality datas for the selected location.
* Browsing through plant list.
* Tracking user plants.
* Generating daily tasks for the household plants.

## Tech Stack

### Architecture
* Backend For Frontend(BFF) pattern
* MVC -kai
* Npm package for shared types

### Frontend

* Typescript
* HTML
* CSS

* Tanstack query

### Backend

### Devops
